# Gameplay Specification: Region Puzzle Design & Vaults

## 1. Region-Specific Puzzle Identities

Each of the six subterranean regions possesses a unique mechanical puzzle theme:

| Region | Puzzle Mechanic | Primary Ember Involved | Description |
| :--- | :--- | :--- | :--- |
| **The Settlement** | Power Grid Routing | Motion / Forge | Routing electrical conduits to activate residential utilities and pumps |
| **The Underlevels** | Minecart & Hydraulic Switches | Motion | Directing pressure switches, pistons, and ore-crushers |
| **The Drowned Districts** | Water Level Manipulation | Guard | Draining and flooding interconnected basins to reveal sunken passages |
| **The Bonelight Warrens** | Light / Darkness Shifting | Bonelight | The map physically shifts in darkness; light beams reveal bridges |
| **The Sunken Archive** | Temporal Memory Replay | Memory | Replaying historical timeline projections to uncover hidden door codes |
| **The Furnace Spire** | Thermal Convection | Forge | Activating thermal updrafts and lava locks to climb the vertical spire |

---

## 2. Vault Dungeons
- Each region conceals a difficult multi-room **Vault Dungeon**.
- Vaults test deep mastery of the region's specific puzzle mechanic without combat distraction.
- Reaching the heart of a Vault rewards an **Anchor Ember** (permanent +1 Ember Capacity upgrade).
